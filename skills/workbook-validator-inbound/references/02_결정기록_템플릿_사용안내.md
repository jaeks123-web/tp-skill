# 02_결정기록 템플릿 — 사용 안내

`references/02_결정기록_템플릿.xlsx`의 사용법이다. **사안 폴더의 `02_결정기록/`에 복사해 쓴다.**
게이트는 이 파일을 만들지 않는다 — **읽고 인수하며, 없으면 이 템플릿의 위치를 안내한다.**

## 왜 양식을 고정하는가

02는 세 문서(01 원본 · 02 결정기록 · 03 전달본)를 잇는 축이다. 양식이 사안마다 달라지면
게이트의 인수 규칙(착수 규율 ②)과 전달본 변환 규격(종결 규율 4)이 매번 다시 쓰여야 한다.
실제로 사안마다 다른 생성 스크립트가 만들어져 열 이름과 판정 어휘가 갈렸고,
색인이 없던 사안에서는 검증 기록 25건을 **사후에 거슬러 작성**해야 했다.

## 시트 넷

| 시트 | 무엇 | 누가 채우는가 |
|---|---|---|
| **작성원칙** | 이 사안의 02를 어떻게 쓰는가 + 사안 고유 규율(R1~R4)·회사 확인요청 번호 | 착수 시 사람이 확정 |
| **결정기록** | 결정 본체 — 13열 | 게이트가 제안, **판정은 사용자** |
| **03위치 검증** | 「03 반영 위치」 토큰을 풀어 실재·값 셀 수를 대조한 결과 | **스크립트** (손으로 쓰지 않는다) |
| **결정·검증 색인** | 각 결정을 **무엇으로 확인했는가** | 게이트가 결정을 적는 **같은 회차에** 함께 |

## 지켜야 하는 규격 셋

### 1. 다섯 칸 — 쟁점 → 검토 대안 → 채택 → 이전가격상 이유 → 03 반영 위치

나머지 열은 이 다섯 칸을 운용하기 위한 것이다. 「이전가격상 이유」는 **이전가격 논리**(FAR·비교가능성·
법령·민감도)로만 적는다. 세부 숫자·명단·경영진 발언은 처음부터 쓰지 않는다 —
**쓰지 않는 것과 다르게 쓰는 것은 다르다.**

### 2. 「사용자 판정」(K열) 어휘 4종 고정

```
채택  /  채택(잠정)  /  미결  /  철회
```

템플릿에 입력 제한이 걸려 있다. 「유지」·「표현수정」은 **채택의 하위 표기**이므로 K열은 「채택」으로 두고
그 취지는 L열에 적는다. 전달본에서 K열은 「확정 상태」(확정 / 잠정 / 미결)로 축약되며,
**채택·철회의 구분은 회사로 나가지 않는다.**

> ⚠️ **사안 종결 전에 K열 공란이 0이어야 한다.** 공란이면 전달본의 「확정 상태」가 빈 채로 나간다.
> 실측: 48행 중 38행이 공란인 채로 전달본이 만들어진 일이 있었고, 토큰 검사로는 잡히지 않았다.

### 3. 「03 반영 위치」는 `시트!범위` 토큰

세미콜론으로 여러 개를 적는다 — `Tap3!A5:O5; Tap3!A6; Tap16!D6`.
「03위치 검증」 시트가 이 토큰을 풀어 **실재 여부와 값이 든 셀 수**를 적는다.

> ⚠️ **「값 1/1셀」이어도 내용이 자리표시자(`—`·`-`·`N/A`)면 불일치로 본다.**
> 실측: 02가 `Tap3!A6`을 가리켰는데 그 셀은 `—` 한 글자였고 실제 주기는 B6에 있었다.
>
> ⚠️ **워크북의 시트명·판본이 바뀌면 이 시트를 다시 돌린다.** 위치 토큰은 판본에 종속된다.

## 색인은 사후에 만들지 않는다

「결정·검증 색인」은 결정을 적는 **같은 회차에** 채운다. 검증 유형은 8종으로 고정되어 있다(입력 제한).

| 검증 유형 | 전달본에서 「대조한 자료 종류」로 바뀌는 예 |
|---|---|
| `원본자료 대조 (01→03)` | 회사 원본자료(인보이스·거래처 원장·감사보고서 주석) |
| `재계산 (독립 재현)` | 정상가격 산출 원본 |
| `법령·지침 원문 대조` | 국조법·국조령·국조칙 및 OECD TPG 원문 |
| `표본 실체 확인` | 비교가능회사 공시자료(감사보고서·공개정보) |
| `검색조건 재현·민감도` | 상용 DB 검색 조건·추출 결과 |
| `외부 수치 대조` | 외부 통계·산업 자료 원문 |
| `시트 간 교차 정합` | 워크북 시트 간 대조 |
| `판단 검토 (정성)` | 계약서·인터뷰·기능분석 자료 |

색인은 전달본에서 **「검증확인표」**(결정 ID · 검증 유형 · 대조한 자료 종류 · 수행일 · 수행 주체)로 변환된다.
**게이트 산출 시트가 빠진 자리를 메우는 유일한 연결 수단**이다 —
실측: 색인이 없으면 02에서 검증 시트로 이어지는 연결의 **47%가 전달본에서 끊어진다.**

## 전달본으로 나갈 때

**여기서 열을 지우지 말라.** 제거는 변환 단계에서 한다(사안 종결 규율 4). 정본은 전 열을 그대로 둔다.

| 단계 | 내용 |
|---|---|
| 열 제거 | 게이트 · 원 발견번호 · **작성자 제안** · 표현수정 지시·비고 |
| 상태 축약 | 「사용자 판정」 → 「확정 상태」 = 확정 / 잠정 / 미결 |
| 행 제거 | 작성자 제안 = 「제외(진행로그)」 / 사용자 판정 = 「철회」 |
| 토큰 제거 | 위치 열의 게이트 시트 토큰(전부 사라지면 「— (검증확인표 참조)」), 보고서 판본(`rev3`) |
| 시트 교체 | 「작성원칙」을 회사판으로 — 내부 작성원칙을 내보내지 않는다 |
| 시트 생성 | 「검증확인표」(색인에서) |
| 시트 제거 | 「결정·검증 색인」 — 내부 문서다 |

> ⚠️ **전달본을 직접 고치지 않는다.** 전달본에서 발견한 것은 **이 정본으로 되돌리고** 다시 만든다.
> 전달본에만 고치면 회사 사본이 회계법인 정본보다 정확해진다 — 두 사안에서 실제로 일어났다.

## 사안 착수 시 할 일

1. 이 파일을 `<사안 폴더>\02_결정기록\02_결정기록_<사안>_v0.1.xlsx`로 복사한다.
2. **작성원칙** 시트의 「사안 고유 규율」과 「회사 확인요청 번호」를 채운다(R1~R4는 착수 규율 ③과 같은 것이다).
3. **결정기록**·**결정·검증 색인**의 노란 예시행을 지우고 D-01부터 쓴다.
4. 「03위치 검증」은 비워 둔다 — 스크립트가 채운다.
