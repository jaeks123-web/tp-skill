# 산업분석 검토 게이트 (Industry Analysis Review)

## Phase 0 — 무결성 확인 (본론 착수 전 1회)

본 스킬은 검증 규율을 누적해 온 파일이며, 다른 TP 스킬과 서로를 지목하며 맞물려 동작한다.
경고문이 지워지거나 구버전이 섞이면 오류를 검출하는 대신 **주입**하게 되므로, 본론에 들어가기
전에 정본 여부를 먼저 확인한다.

**실행 방법 — 스킬 폴더를 탐색해서 이동한 뒤 실행한다.**

```bash
D=$(find ~ / -maxdepth 8 -type d -name "industry-analysis-review" -path "*skills*" 2>/dev/null | head -1)
cd "$D" && python3 scripts/verify_skills.py
```

⚠️ **스킬이 안내하는 base directory 경로를 그대로 쓰지 말 것.** 그 경로는 Windows 형식
(`C:\Users\...`)인데 명령을 실행하는 셸은 **Linux 경로 체계**를 쓴다. 같은 폴더인데 이름이
달라 `No such file or directory`가 난다(실행 검증에서 실제로 확인한 오류다).
위 탐색 방식은 **경로 체계와 무관하게 동작**하며 약 1초 걸린다.

폴더 안에서 실행하면 **인자가 필요 없다.** 스크립트가 루트와 대상 스킬을 스스로 판별한다.

- **합격** — 그대로 진행한다. 별도로 보고하지 않는다.
- **변조·누락** — **작업을 중단하고 사용자에게 고지**한다. 어느 파일이 정본과 다른지 알린다.
  사용자가 진행을 지시하면 「무결성 미확인 상태」임을 답변에 명시하고 진행한다.
- **실행 불가**(경로·스크립트·매니페스트 없음) — 검증을 **생략하되 침묵하지 않는다.**
  한 줄로 「무결성 확인 미실행」을 알리고 진행한다.
- **`[미설치] tp-case-law`가 보이면** — 본 스킬이 조문·판례 검증을 tp-case-law에 맡기는
  부분은 실행되지 않는다. 해당 단계에서 그 사실을 고지하고, 조문 인용은 「확인 필요」로 표기한다.

⚠️ **이 절차는 변조를 막지 못한다. 드러나게 할 뿐이다.** 매니페스트(`scripts/MANIFEST.sha256`)가
함께 바뀌면 검증은 통과한다. 배포 시에는 매니페스트를 변경 이력이 남는 곳에도 보관하고 대조한다.

## 0. 기본 원칙

- **전제**: Tap4(요소 평가)·Tap4-1(서술)은 AI 분석 또는 ABC_TP_Tool 연동으로 생성되고
  실무자가 보정한다. Claude는 수치·논리·사실 정합성을 **검토·자문**하며, **최종 판단 권한은
  항상 사람에게 있다**. 점수 자체의 재평가 대행이 아니라 근거·일관성의 검증이다.
- **실행 시점**: Tap4 계열 완성 직후 · Tap12-1(가치사슬 스코어링) 착수 전.
  산업요소 조정점수는 가치사슬 Score(= FAR × VC Scale × 조정점수)의 곱수이므로,
  여기서 확정하지 않으면 기여율·특성분류까지 연쇄로 흔들린다.
- **게이트 원칙**: 각 Phase는 「검토 → 발견사항 보고 → 사용자 확정」후 `progress.md`에
  기록한다. 구동 지시어 "Phase N 실행", 순서 0 → 1 → 2 → 3 → 4.
- **규범·사실 쟁점**: 법령·TPG 해석은 tp-case-law 스킬로, 외부 경제지표·산업 통계의
  사실 확인은 웹서치로 검증하고 출처를 인용한다.
- **연계**: 본 게이트의 「조정점수 정본 확정표」는 characterization-gate Phase 0
  (기준 버전 확정)의 입력이 된다. tp-report-writer Step 3(제III장 산업분석)은
  본 게이트 완료를 전제로 실행한다.

### 검토 대상 구조

```
Tap4-2 (Scale 1~5 기준 사전: 대분류 5개 × 산업요소 25개 + 수익률강도 정의)
  → Tap4 (요소별 시장강도·수익률강도 평가 + 조정점수 + Scale 근거 서술)
  → Tap4-1 (산업·경제환경 서술 + TP 시사점)
  → [하류] Tap12-1·ABC_TP_Tool (조정점수를 Score 산식에 사용)
```

## 1. Phase 0 — 인수 기준

1. **워크북 원본 xlsx** — Tap4·Tap4-1·Tap4-2 완비.
2. **조정점수 산식 확인** — 조정점수가 시장강도·수익률강도에서 어떻게 산출되는지
   (예: 가중평균 0.6×시장 + 0.4×수익률) 명문화된 정의를 확인. 정의가 없으면 값에서
   역산해 추정치를 제시하고 **사용자에게 산식을 확정**받는다 (산식 미기록 자체가 발견사항).
3. **ABC_TP_Tool 스코어링 파일** (있으면) — 하류 대조(Phase 4)용. 버전 명기.
4. **분석대상 산업 정의** — 산업 명칭·범위(예: 자동차 차체부품)와 대상 법인·소재국 확정.


**5. 산업 자료원 접근성 점검** — 산업지표 대조(Phase 3-1-1)에 사용할 자료원의 접근 가능 여부를 착수 시점에 확정한다.

| 자료원 | 접근 | 확인 사항 |
|---|---|---|
| 웹 공개 통계 (OECD·IMF·World Bank·각국 통계청·업종 협회) | 무료 | 해외·글로벌 산업의 1차 경로 |
| **NICE BizLINE 「산업 → 산업 요약」** | **유료·로그인 필요** | **국내 산업(KSIC 기준)**의 시장 규모·시장집중도(HHI/CR)·계량산업등급·부도/연체/휴폐업률·산업 평가의견. 접근이 필요하면 아래 고지 문안으로 질문한다 |
| **S&P Capital IQ (웹 화면)** | **유료·로그인 필요** | **해외·글로벌**의 S&P Global PMI™ · Country Risk Scores · Currency Exchange Rates · Investment & Market Research. **Industry Trends & Statistics는 커버리지가 한정**되므로 Phase 3-1-1 ⓓ 참조 |

⚠️ **URL을 기록·재사용하지 않는다.** BizLINE의 `/workspace/...` 경로는 **세션마다 새로 생성되는 토큰**이며(실측: 같은 화면이 `7Uct`→`3zhe`로 변경) 산업코드에 대응하는 영구 링크가 아니다. **반드시 「산업 → 산업 요약」에서 대상 KSIC 코드로 직접 조회**하고, 조서에는 URL이 아니라 **조회한 KSIC 코드와 조회일**을 기록한다.

**로그인 자료원 고지 문안** — Claude는 사용자 계정으로 로그인하지 않는다. 필요 시:
```
[산업 자료원 접근 확인 필요]
① 필요 자료 : {자료원} — {KSIC 코드/관할}({산업명})의 {항목}
② 사용 목적 : Phase 3 산업지표 대조 — Tap4 {시장강도/수익률강도} 근거 검증
③ 대체 가능성 : 공개 통계로 일부 대체 가능하나 HHI·계량산업등급은 BizLINE 고유,
                PMI·Country Risk Scores는 CIQ 고유
④ 선택지 (a) 직접 조회 후 값 전달 (b) 공개 통계로 우회 (c) 미확인 처리 후 한계 명시
```

게이트: 3종 인수 + 조정점수 산식 확정 + **산업 자료원 접근성 확정**.

## 2. Phase 1 — 구조·수치 정합성 (스크립트 전수 검증)

1. **요소 목록 완전성** — Tap4의 산업요소가 Tap4-2 기준 사전(표준 25개)과 1:1 대응하는지.
   누락·추가·명칭 불일치 검출.
   ⚠️ **실전 검출례**: Tap4 평가표에 '시장 집중도'가 누락(24개)된 반면 Tap4-2 기준과
   Tap12-1의 25개 연결 구조에는 존재 — 하류가 참조하는 요소가 상류에 없는 상태.
2. **점수 유효성** — 시장강도·수익률강도가 1~5 범위의 유효값인지, 대분류 배정이
   Tap4-2와 일치하는지.
3. **조정점수 재계산** — Phase 0 확정 산식으로 전 요소를 독립 재계산해 기재값과 대조.
4. **대분류 구성** — 5개 대분류(시장구조/수익성/기술·무형/생산·공급/규제·제도)별 요소 수와
   순서가 Tap4-2·Tap12-1 구조와 일치하는지.

불일치는 각각 사용자 택일 확정(① 점수 수정 ② 기준 사전 수정 ③ 의도된 것 논거 보강).

게이트: 25개 요소 완전성 확보, 조정점수 전수 재계산 일치.

## 3. Phase 2 — Scale 기준 적용 검토

Tap4의 요소별 근거 서술이 Tap4-2 기준 사전을 올바로 적용했는지 검토한다.

1. **라벨 일치** — 서술 내 "시장 N(라벨)" 표기의 N이 시장강도 열 값과 일치하는지,
   라벨이 Tap4-2의 해당 Scale 정의와 부합하는지 (동의어 수준 차이는 허용, 등급 상이는 오류).
2. **수익률강도 판정 근거** — 수익률강도 값이 Tap4-2의 수익률강도 정의(1: 영향 없음 ~
   5: 초과이익 핵심 원천)와 실무 판정 기준에 비추어 서술과 정합하는지.
   특히 4~5점(고마진·잔여이익 요인) 부여 요소는 무형자산·DEMPE 논거와 연결되므로 중점 검토.
3. **사실 근거 대조** — 서술이 인용하는 회사 사실(표준가격 구조, 무상사급, 공법기준서,
   설비투자 등)이 워크북 근거 시트(Tap2·5·6·8)와 모순되지 않는지 — 목적 지향 추출로 확인.
4. **점수 간 논리 일관성** — 상충 신호 검출 (예: '무형 집중도' 상위 점수인데
   '기술 무형자산 중요성'이 하위, '대체재 존재' 낮음인데 '시장 경쟁 강도' 극심 등).
   상충은 오류 단정이 아니라 설명 요구 사항으로 보고한다.

게이트: 요소별 적용 검토표 완성, 상충 전건 확정.

## 4. Phase 3 — 서술(Tap4-1) 검토

보고서 제III장의 원천이 되는 서술의 품질을 검토한다.

1. **사실·수치 검증** — 외부 인용 통계(물가상승률, 기준금리, GDP 전망, 시장 규모 등)를
   웹서치로 확인: 수치의 정확성, 출처 실재, **기준 시점의 최신성**(분석기준일 대비 구 데이터
   사용 여부). 확인 결과를 출처 링크와 함께 기록한다.
1-1. **산업지표 대조 (자료원 확보 시)** — Tap4의 시장강도·수익률강도 근거를 외부 산업지표와 대조한다.

   | 대조 항목 | 대응 Tap4 요소 | 자료원 |
   |---|---|---|
   | 시장 규모·규모 추이 | 시장강도(시장 규모·성장성) | 공개 통계 / BizLINE 「산업 규모 추이」 |
   | **시장집중도(HHI·CR)** | 시장강도(경쟁 정도) — **국조칙 §6①6호 「경제 여건: 시장의 경쟁 정도」**에 직접 대응 | BizLINE 「시장 집중도」 |
   | 계량산업등급 · 부도율/연체율/휴폐업률 | 수익률강도·산업 위험 | BizLINE 「산업 위험」 |
   | 산업 평가의견(정성 진단) | Tap4-1 서술의 사실 검증 | BizLINE 「산업 설명 — 평가의견」 |
   | **국가별 경기 국면** | 시장강도(경기 민감도) · 검증대상 실적 부진의 시장환경 논거 | CIQ **S&P Global PMI™** — 국가별 제조업/서비스/종합, 월별·추이 |
   | **관할 위험·시장 상이성** | 시장강도 · **표본 부족 시 비교군 지역 확대의 타당성 논거** | CIQ **Country Risk Scores** — Overall + 정치·경제·법률·조세·운영·보안 6개 하위점수 |
   | 환율 | 경제환경 서술 · 비교가능성 조정의 기초 | CIQ **Currency Exchange Rates** — 사내 자료 간 환율 불일치 시 정본 후보 |
   | 산업 집계 수익성(ROAA 등, 5개년) | 수익률강도 | CIQ **Industry Trends & Statistics** — ⚠️ **커버리지 한정**(ⓓ) |

   **대조 시 필수 확인 4종** (미확인 시 인용 금지):
   - ⓐ **산업코드 일치** — 화면에 표시된 자료가 **대상 KSIC의 것인지** 확인한다. 세분류에 대응 자료가 없으면 **상위·유사 코드 자료가 대체 표시**된다. 실측례: 대상이 **G46750**(종이 원지·판지·종이상자 도매업)인데 「NICE 최신 산업 보고서」는 **G4680000**(상품 종합 도매업), 「최신 산업 통계」는 산업명이 **「종합상사」**에 갱신일 **2015.01.12**였다. 그대로 인용하면 본 Phase가 잡아야 할 출처 불일치를 스스로 만들게 된다.
   - ⓑ **기준연월 병기** — 항목마다 기준 시점이 다르다(실측: 산업 규모 2025 / 연관 코드 2023 / 산업 위험 2026.06). **과세연도와의 정합**을 확인하고 조서에 기준연월을 함께 적는다.
   - ⓒ **관점 한계 명시** — BizLINE은 **KSIC 기준, 즉 제품 관점**만 제공한다. **기능 관점 동종회사는 보완되지 않으므로**(Phase 0 산업 이중 관점 참조) 기능 관점 근거는 별도 확보한다.
   - ⓓ **CIQ 산업·경제 데이터의 한계 (2026-08 실측)**
     - **PMI는 제조업·서비스 2분류까지**다. 「자동차부품 PMI」 같은 세부 산업 지표는 존재하지 않는다. **국가 단위 시장환경 논거로만** 쓰고, 세부 산업 판단의 근거로 쓰지 않는다.
     - **Industry Trends & Statistics의 산업 목록은 금융·보험·미디어통신·에너지·금속광물에 한정**된다(구 SNL Financial 계보의 커버리지가 남아 있는 구조). **일반 제조업·도소매업은 없다.** 해당하지 않으면 Screener로 상장사를 뽑아 직접 집계하는 우회 경로를 쓰되, **상장사 기준임을 서술에 반드시 명시**한다(모집단이 산업 전체가 아니다).
     - **한국 산업 데이터의 정본은 KOSIS·한국은행·산업연구원**이다. CIQ는 해외·글로벌 보완용으로 쓴다.
     - **CIQ MCP(Kensho LLM-ready API)로는 위 지표를 조회할 수 없다.** MCP 제공 데이터셋 5종(Latest Financials·Business Relationships·Earnings Call Transcripts·Company Intelligence·Transactions)에 PMI·Country Risk·환율·리서치가 포함되지 않으며, 이들은 **웹 화면 전용**이다. MCP 연결 여부와 무관하게 §5 고지 문안으로 조회를 요청한다.

   ⚠️ **산업지표는 근거 자료이지 점수 산출기가 아니다.** 시장강도·수익률강도 Scale은 Tap4-2 기준에 따른 실무자 판단이며, 본 스킬은 **근거와의 정합성 검증까지만** 한다(§8 경계).
   ※ 기업 목록·산업 내 매출 순위·상장/외감 구분은 산업분석 소관이 아니다 — **comparable-search-review(-inbound) Phase 1B 모집단 교차검증·Phase 3B C군 발굴로 이관**한다.

2. **Tap4 점수와 논조 일치** — 서술의 강도 표현이 점수와 어긋나지 않는지
   (예: '완만한 성장' 서술 ↔ 성장률 점수, '치열한 경쟁' ↔ 경쟁강도 점수).

   Tap14·16의 실제 방법 결정과 일치하는지. 소재국 경제환경 시사점(고인플레·환율 불안 →
   비교가능성 조정 필요)이 Tap15 검색전략·Tap17 조정계산에 실제로 반영되었는지 확인

## 8. 경계 (중요)

### 검증 규율 2항 (전 게이트 공통)

**1. 원자료를 확인하기 전에 「통제 부재」를 단정하지 않는다.**
게이트가 「통제가 없다」·「기준이 이름만 있다」·「설계가 잘못되었다」고 **판정하려면, 그 판정을
뒤집을 수 있는 원자료를 먼저 확인**한다. 집계 지표(결측률·분포·비율·공란 개수)만으로 설계
결함을 단정하지 아니한다.
- 판정을 조서에 **기재하기 전에** 「이 수치가 정상 설계에서도 나올 수 있는가」를 1회 자문한다.
- 원자료를 확인할 수 없으면 **「미확인」으로 적는다. 「없다」로 적지 않는다** — 둘은 다른 진술이다.
- 이 규율은 **발견을 줄이려는 것이 아니다.** 틀린 A등급은 진짜 A등급의 신뢰를 함께 떨어뜨린다.

**2. 다른 게이트·다른 단위의 판단을 원용할 때는 그 현재 상태를 직접 확인한다.**
「선행 게이트에서 해소되었다」·「같은 기준을 적용하였다」·「전기 조서에서 확인되었다」는 기재는
**그 자체가 검증 대상**이다. 원용하기 전에 그 판단의 현재 상태를 직접 확인하고, 확인 방법을
조서에 적는다.
- **기록과 실제는 갈릴 수 있다.** 「해소」로 적힌 것이 미해소일 수 있고, 「동일 기준」이라 적힌
  것이 실제로는 다른 기준일 수 있다.
- 확인하지 못했으면 **원용하지 않는다.** 원용을 생략하고 직접 판단하거나, 미확인 사실을 함께 적는다.

⚠️ 실전 검출례(Case 002) — 규율 2: 조정점수의 정본 원천이 **Tap4 A2와 IAR 확정표 A2 두 곳**에
기재되어 갱신이 어긋났다(Tap4 「v7」 ↔ 확정표 「v9」). 원용 전에 어느 쪽이 마스터인지 확인한다(§5).


- 시장강도·수익률강도 점수의 재평가를 대행하지 않는다 — 근거 서술과의 정합성 검증까지만.
- 외부 통계 검증에서 상이한 최신 수치를 발견해도 직접 교체하지 않는다 — 출처와 함께
  보고하고 사용자 확정 후 반영한다.
- Tap4-1 서술의 문체·표현 정리는 제안까지만. 보고서 문체 변환은 tp-report-writer
  Step 3의 소관이다.
